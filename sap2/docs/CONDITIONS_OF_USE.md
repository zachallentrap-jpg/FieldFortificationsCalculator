# CONDITIONS_OF_USE.md

**DRAFT v1 — wording pending counsel review (COUNSEL_REVIEW.md q.1). The in-app
conditions gate requires a typed-name acceptance of this document on first run and
again on data-class escalation.**

1. **What this tool is.** SAP-2 is a planning aid. It computes geometry, material,
   and labor estimates from values **you** provide. It ships with no doctrinal
   values and looks nothing up for you.
2. **What it is not.** It is not a publication, not engineering judgment, not a
   safety authority, and not a substitute for any of those. No output of this tool
   authorizes construction.
3. **Your data, your responsibility.** Every doctrinal value the tool uses was
   entered, cited, and verified by a person whose attested identity is recorded with
   it, and accepted by a commissioner in a recorded act. The tool enforces the
   recording, not the correctness.
4. **Marked outputs mean what they say.** TEMPLATE, TRAINING, UNVERIFIED, and STALE
   watermarks are load-bearing. Building from a watermarked sheet is use against the
   conditions.
5. **Engineered-roof threats.** For threats the schema marks engineered-required,
   the tool refuses to size overhead cover at any data state. Route those positions
   to engineer support.
6. **Verify forward.** Publications change. Check outputs against current pubs and
   the defect advisories (`DEFECT_ADVISORIES.md`) for your app version.
7. **Handling.** Follow `HANDLING.md` for fill files and outputs until counsel
   review returns a definitive posture.
